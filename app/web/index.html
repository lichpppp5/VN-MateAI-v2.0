— tự làm mới mỗi 10s
TÊN THIẾT BỊ / HOSTNAME ĐỊA CHỈ IP LAN HỆ ĐIỀU HÀNH SỐ KỸ NĂNG KẾT NỐI LÚC THAO TÁC
⚠️ Không lấy được danh sách máy trạm từ máy chủ. Số liệu bên trên giữ nguyên lần tải gần nhất — đây là lỗi kết nối, không phải "không có máy trạm nào". Bấm nút ↻ để thử lại.
🖥️

Chưa có máy trạm nào kết nối

Khởi chạy Client Agent trên các máy con trong cùng mạng LAN để kết nối về máy chủ này, hoặc bật ngay Worker Cục Bộ để thử nghiệm tức thời.

ℹ️

Thêm máy trạm mới: bấm Tải Agent, giải nén sang máy con rồi chạy python agent.py — địa chỉ máy chủ và token đăng ký đã nằm sẵn trong gói.

1. Máy con cần cài Python 3.10 trở lên và 2 thư viện: pip install websockets psutil.

2. Chạy agent ở máy con — không cần truyền tham số nào, địa chỉ máy chủ lấy từ config.json trong gói:

python agent.py

3. Xem tên máy con tự sinh ở bảng bên trên. Muốn đặt tên riêng: python agent.py --id "TEN_MAY".

Kết nối dùng ws:// nếu máy chủ chạy HTTP, wss:// nếu chạy HTTPS (khi đó agent kiểm tra chứng chỉ server_cert.pem đi kèm trong gói). Mỗi lần bấm "Tải Agent" là một gói mới với token đăng ký mới.
